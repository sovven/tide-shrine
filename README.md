# 潮の社 · Tide Shrine

日式潮汐神社 Three.js 小场景——浮世绘渐变色带、竖排标题、印章，潮起潮落与昼夜变化。

在线体验：https://sovven.github.io/tide-shrine/

单文件 `index.html`，Three.js 0.160（jsdelivr importmap），直接用浏览器打开即可。

## 精细版 · 弐

在线体验：https://sovven.github.io/tide-shrine/v2/

按严岛神社寝殿造细化：桧皮葺屋顶、椽子与斗栱、蔀户格子、擬宝珠高栏、春日灯笼、五重塔相轮；程序化木纹/朱漆/潮痕材质，吉卜力式树冠与草地，浮在积云之上。
